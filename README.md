# shivamsharma.co — my room

The homepage is an illustrated bedroom. Click an object to zoom into it:

| Object        | Page                     |
|---------------|--------------------------|
| Bookshelf     | Books I've read (`#/books`) |
| PC            | Video games (`#/games`)  |
| TV            | Movies & TV (`#/watching`) |
| Record player | Music (`#/music`)        |
| Corkboard     | About me + contact (`#/about`) |

The old professional portfolio lives at [`/work/`](work/).

## Adding stuff

Everything (books, games, movies, shows, albums, about text) is in **`js/data.js`**.
Edit it, commit, push — no build step.

## Files

- `index.html` — the room illustration (inline SVG) and page shells
- `css/room.css` — all styles
- `js/room.js` — zoom transitions, routing, page rendering
- `js/data.js` — your content
